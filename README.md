# 慢慢来 · Personal Desk

纸张与桌面空间交互的个人工作台。原生 HTML / CSS / JavaScript，无构建依赖。

## 本轮更新

- 分区和文件夹直接拖动；位移超过 6px 才开始拖动，否则按点击打开。
- 拖动代理固定尺寸，逐帧仅更新 translate3d；只在松开时保存坐标。Escape、指针取消、窗口失焦会取消拖动。
- 移除底部投放条。直接拖入真实分区/文件夹，目标边框显示“放入”。卡片详情也保留目标选择操作。
- 完成任务先保存状态、完成时间和原归属，再短暂显示 DONE；自动进入 Archive。恢复任务后重新激活，保留纸张身份、内容、清单、附件、标签及操作历史。
- 新建分区、重命名、归档、删除；标题旁 ··· 菜单支持键盘和触屏。分区删除进入废纸篓，可以恢复。
- 整个项目归档后从桌面与 TODAY 隐藏，文件夹与纸片仍保留在 Archive。恢复项目不会恢复已单独完成的任务。
- 保留原纸张配色、纸纹和文件夹形态。标题和正文使用小赖手写体 400 字重，日期与辅助信息使用规整字体，图标具有名称和悬停提示。
- 旧版本数据自动迁移为 v2；已有 DONE 卡片进入 Archive，缺少的旧完成时间显示“未记录”。迁移前保留原始备份键。

## 纸张与拖动反馈

- 轻微纸角差异、稀疏胶带和折角、短距离接触阴影；纹理位于文字下方。
- 拿起 140ms、最大 1.5% 放大、速度倾斜限制 ±2.2°；旋转和缩放补偿抓取点，不改变鼠标跟随位置。
- 松手 165ms 归位，文件夹标签和边缘提供接收反馈；尊重减少动态效果设置。
- pointermove 只记录输入，requestAnimationFrame 更新 transform；仅松手持久化。

## 使用与数据

点击分区进入文件夹；点击文件夹展开；点击纸片编辑。顶部/底部 ＋ 新建纸片，默认进入 INBOX。⌘K / Ctrl+K 检索；Escape 关闭抽屉或取消拖动。导出、导入 JSON 用于备份。

卡片归属 home_area/home_module 与当前位置 surface/lane 分离。visual_dna 保持纸张身份。分区生命周期与卡片完成状态独立。桌面和窄屏使用不同坐标记录，避免桌面位移把手机内容移出视野。

数据仅保存到当前浏览器 localStorage，不支持跨设备同步。小赖字体以本地 WOFF 分片加载，附 OFL 1.1 许可；生僻字回退到本地中文字体。附件单个最大 1 MB。无追踪脚本与凭据。

## 发布

GitHub Pages 从 main 分支根目录发布。无需 Actions 工作流、安装依赖或构建。

## 验证

```sh
node --check app.js
node test-model.mjs
node test-app.mjs
```

模型检查覆盖旧数据迁移、动态项目、完成时间、任务/项目归档与恢复、删除恢复、序列化与输入校验。应用检查使用最小 DOM 适配器覆盖启动与页面生成，并检查 6px 点击阈值、300px 位移保存、拖动过程不写存储、指针取消和滚动补偿；另检查倾斜方向与上限、抓取点补偿、减少动态效果和稳定的纸张样式；不等同于浏览器手感测试。

本轮云浏览器访问本地预览被 URL 策略阻止，尚未完成实际指针拖动、视觉和移动端浏览器验收。
