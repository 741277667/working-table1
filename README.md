# 慢慢来 · Personal Desk

纸张与桌面空间交互的个人工作台，静态 HTML / CSS / JavaScript，无构建依赖。

## 使用

部署目录为仓库根目录。GitHub 仓库 Settings → Pages → Source 选择 Deploy from a branch，分支 main，目录 / (root)。后续推送自动更新网站。

- 五个区域：自媒体、毕业设计、兼职、工作、生活，点击区域标题进入模块。
- ＋ 默认创建 NOTE，Enter 收好；可选择 TASK / LIST / PROJECT / SAVE。
- 单击打开，鼠标拖动移动；触屏长按约 220ms 再拖动。详情页也可选择区域和模块移动。
- 卡片经过底部区域标签约 400ms 展开模块。拖至同区域同模块另一张卡停留约 500ms 可组成纸堆。
- TODAY 保留原归属地索引；四个分区 NOW / TODAY / IF I WANT / WAITING。
- ⌘K / Ctrl+K 检索；Escape 关闭抽屉；Tab 可在打开的详情页内导航。
- 编辑描述、笔记、清单、日期、状态、链接和附件；附件单个最大 1 MB。
- 8 种纸张身份跟随卡片；DONE / WAITING 通过印章显示。
- 归档、废纸篓、恢复及撤销；只有废纸篓可永久删除。
- 布置模式通过红色把手调整区域与模块位置，右下角调节尺寸；可增删模块，删除模块时纸片回 INBOX。
- 导出 / 导入 JSON 备份。

## 数据与范围

所有数据仅保存到当前浏览器的 localStorage，不会写入 GitHub。不支持跨设备同步或登录。首次加载的示例卡片用于演示，可编辑删除；不是从用户真实工作记录获取的数据。浏览器存储通常容量有限，附件过多时请导出备份。

卡片归属 `home_area / home_module` 与当前摆放 `surface / lane` 分离；纸型与旋转 `visual_dna` 永久保留。卡片在模块内的位置为有限偏移，避免小屏幕溢出；布置模式为自由位置微调。已有堆叠按展开/收拢呈现。SAVE 使用文件卡与附件记录，未提供文件差异比较；研究地图为可摆放的研究卡片模块，未提供连线编辑器。

字体来自 Google Fonts（不可用时使用本地衬线字体）。没有分析或追踪脚本。不含任何凭据。

## 检查

`node --check app.js`

不需要 npm 安装。无后端接口或构建过程。
