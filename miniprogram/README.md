# 慢慢来 · 微信小程序

在微信开发者工具中导入本目录（`miniprogram/`），即可预览。`project.config.json` 使用 `touristappid`，发布前需要替换为自己的小程序 AppID，并完成微信平台要求的类目与备案。

不装微信开发者工具时，也可直接打开 `preview.html` 体验手机尺寸的浏览器流程。它是交互模拟页，不代表微信渲染、输入法或真机触摸效果。

小程序在设备本地保存 `personal-desk-v1` 桌面数据，沿用网页 v1/v2 数据结构。网页浏览器和微信小程序各自有独立的本地存储；跨端迁移请在小程序顶部导出 JSON 文件，再通过“导入”从微信聊天文件中选择备份。

目前实现桌面分区、文件夹、纸片详情、连续录入、LIST 连续加项、完成归档、废纸篓、恢复、搜索、备份导入导出。桌面纸片长按约 220ms 后可拖到分区或文件夹；系统提供 reduced motion 标记时会关闭旋转和振动。仍需在微信开发者工具和真机上检查输入法候选键行为、不同微信基础库的触摸手势以及安全区适配。

运行最小逻辑检查：

```sh
node --check app.js
node --check pages/index/index.js
node check.cjs
```
